# ShopBar Market — ร้านค้าออนไลน์ส่งเองในชัยนาท

หน้าร้านสไตล์ Shopee สำหรับขายสินค้าที่ **เจ้าของร้านจัดส่งเอง** ในจังหวัดชัยนาทและพื้นที่ใกล้เคียง
มีตะกร้า สั่งซื้อ ติดตามสถานะ และ **แชทสอบถามแบบ realtime** ระหว่างลูกค้ากับร้าน

| หน้า | URL | ใช้ทำอะไร |
|---|---|---|
| หน้าร้าน (ลูกค้า) | `/shop/` | ดูสินค้า ค้นหา ใส่ตะกร้า สั่งซื้อ ดูสถานะ แชทกับร้าน |
| หลังร้าน (เจ้าของ) | `/shop/admin.html` | ลงสินค้า+รูป จัดการสต๊อก ดู/อัปเดตออเดอร์ ตอบแชท |

ลูกค้า **ไม่ต้องสมัครสมาชิก** (ใช้ Supabase anonymous session ผูกกับเบราว์เซอร์ของลูกค้า)

## ติดตั้งครั้งแรก (ประมาณ 5 นาที)

1. **สร้างตาราง** — เปิด Supabase > SQL Editor > วางไฟล์ `shop/schema.sql` ทั้งไฟล์แล้ว Run
   (รันซ้ำได้ ไม่ทำให้ข้อมูลหาย)
2. **เปิด Anonymous sign-ins** — Authentication > Providers > *Anonymous* > เปิด แล้ว Save
   (ถ้าไม่เปิด ลูกค้าจะแชท/สั่งซื้อไม่ได้ หน้าร้านจะบอกว่า "ยังไม่ได้เปิด Anonymous sign-ins")
3. **สร้างบัญชีแอดมิน** — Authentication > Users > *Add user* > ใส่อีเมล+รหัสผ่าน และติ๊ก *Auto Confirm User*
4. **ตั้งเป็นแอดมินร้าน** — SQL Editor รัน (แก้อีเมลให้ตรง):
   ```sql
   insert into public.shop_admins (user_id)
   select id from auth.users where email = 'you@example.com'
   on conflict do nothing;
   ```
5. (ไม่บังคับ) รัน `shop/seed.sql` เพื่อใส่สินค้าตัวอย่าง 8 รายการ
6. เปิด `/shop/admin.html` เข้าสู่ระบบ แล้วเริ่มลงสินค้าได้เลย

## ตั้งค่าร้าน

แก้ไฟล์ `shop/shop-config.js`
- `SHOP_NAME`, `TAGLINE`, `PHONE`, `LINE_ID`, `PROMPTPAY`
- `DELIVERY.fee` ค่าส่งมาตรฐาน, `DELIVERY.freeOver` ยอดที่ส่งฟรี (0 = ไม่มี)
- `DELIVERY.areas` รายชื่ออำเภอ/จังหวัดที่ส่ง พร้อมค่าส่งแต่ละพื้นที่ (`fee: null` = ให้ลูกค้าสอบถามทางแชท)
- `CATEGORIES` หมวดหมู่ที่แนะนำตอนลงสินค้า

## การทำงานฝั่งฐานข้อมูล (สรุป)

- **ราคา/ยอดรวมคำนวณที่ฐานข้อมูล** เสมอ (trigger) ลูกค้าแก้ราคาจากหน้าเว็บไม่ได้
- สั่งซื้อแล้วตัดสต๊อกทันที และ **ยกเลิกออเดอร์จะคืนสต๊อกให้อัตโนมัติ**
- ทุกออเดอร์ถูกส่งเป็นข้อความเข้าห้องแชทของลูกค้า และเมื่อร้านเปลี่ยนสถานะ ลูกค้าจะได้รับแจ้งในแชท
- Row Level Security: ลูกค้าเห็นเฉพาะออเดอร์/แชทของตัวเอง แอดมิน (ตาราง `shop_admins`) เห็นทั้งหมด
- รูปสินค้าเก็บใน Storage bucket `product-images` (ย่อรูปอัตโนมัติก่อนอัปโหลด ไม่เกิน 1000px)

## หมายเหตุ

- ถ้าเปิดหน้าร้านโดยยังไม่ได้รัน `schema.sql` จะแสดง **โหมดตัวอย่าง** (สินค้าจำลอง สั่งซื้อ/แชทไม่ได้)
- ห้องแชทผูกกับเบราว์เซอร์ของลูกค้า ถ้าลูกค้าล้างข้อมูลเบราว์เซอร์จะได้ห้องใหม่ (ประวัติเดิมยังอยู่ในหลังร้าน)
- แอดมินถ้าเปิดหน้าร้านในเบราว์เซอร์เดียวกัน จะเห็นแชทในฐานะลูกค้าของ "ตัวเอง" — ทดสอบด้วยหน้าต่างไม่ระบุตัวตนแทน
