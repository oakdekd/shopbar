# เทสของเครื่องมือวิเคราะห์คลิปเทนนิส

## 1. เทสส่วนคำนวณ (ไม่ต้องพึ่งอะไรเลย)

```bash
node --test test/tennis-analysis.test.mjs
```

ทดสอบ `tennis-analysis.js` ด้วย pose สังเคราะห์ที่จำลองรูปร่างสวิงจริงของแต่ละชนิดลูก
(ท็อปสปิน / แฟลต / สไลซ์ / เสิร์ฟ / วอลเลย์สูง) ตำแหน่งข้อศอกวางด้วย inverse kinematics
มุมศอกจึงเป็นไปตามระยะไหล่-ข้อมือจริง ไม่ใช่ค่าที่ตั้งเอง

ครอบคลุม: การนับจำนวนสวิง ความแม่นของเวลา การแยกชนิดลูกและฝั่ง มือถนัดซ้าย
การเติมเฟรมที่ pose หายไป คลิป 30 fps คลิปที่ไม่มีคนเลย และรูปแบบ landmark ทั้งแบบ
อ็อบเจกต์ แบบ `Float32Array` อัดแน่น และแบบเบาบาง

## 2. เทสหน้าเว็บทั้งหน้า (ต้องมี Playwright + Chromium)

```bash
node test/e2e.mjs
```

รัน `tennis.html` ใน Chromium จริง โดย:

- สร้างคลิป webm สั้น ๆ ขึ้นมาเอง (เนื้อหาในภาพไม่มีผล)
- ดัก request ไป CDN แล้วตอบด้วย `test/mediapipe-stub.js` ซึ่งปล่อย pose สังเคราะห์
  ตามเวลาในคลิป — จึงไม่ต้องต่ออินเทอร์เน็ตและไม่ต้องมีคลิปเทนนิสจริง
- ตรวจตั้งแต่การดึงเฟรม การนับช็อต การแยกชนิดลูก การแก้ label เอง การเพิ่ม/ลบช็อต
  การส่งออก CSV การวาดกราฟและโครงร่าง ไปจนถึงการสลับมือถนัด

ปรับ path ของเครื่องมือได้ด้วยตัวแปรแวดล้อม `PLAYWRIGHT_MODULE`, `CHROMIUM_BIN`, `FFMPEG_BIN`
